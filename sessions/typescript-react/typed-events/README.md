# TypeScript React: Typed Events

This challenge is about typing event handlers for inputs, selects and forms.

## Tasks

The tasks for this challenge are outlined in the comments inside the `./src/App.tsx` file.

The starter code is a small sign-up form. The event handlers have no types yet.

## Notes

- You only have to touch the `./src/App.tsx` file.
- Hover over `event` in an inline handler such as `onChange={(event) => ...}` to see which type TypeScript infers. Then use that type when you move the handler into its own function.

## Development

To work locally, please install the dependencies using `npm i` first.

Run `npm run dev` to start a development server and open the displayed URL in a browser.

Run `npm run check` to let TypeScript check all types without running the code. Your editor shows the same errors, so keep an eye on the red squiggles.
