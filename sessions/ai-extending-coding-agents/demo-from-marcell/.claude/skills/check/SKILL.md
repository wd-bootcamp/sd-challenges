---
name: check
description: Run the type check and the tests of the project and report the result. Use this when the user asks to check or verify the project, or asks whether everything still works. Never edits files.
---

Check the project. Do not edit, create or delete any files.

1. Run `npm run check`.
2. Run `npm run test:run`.
3. Report whether both passed. For every failure, name the file, the test or the line, and the reason in one sentence.
