# Chat AIs vs Coding Agents: Demo

The Movie Tracker from the TypeScript React session, now with Vitest. It contains a bug: the liked summary always says that every movie is liked, and the like button seems to do nothing.

Clone this demo to your computer:

```sh
npx ghcd@latest wd-bootcamp/sd-challenges/tree/main/sessions/chat-ai-vs-coding-agents/demo -i
```

## Development

To work locally, please install the dependencies using `npm i` first.

Run `npm run dev` to start a development server and open the displayed URL in a browser.

Run `npm test` to run the tests with Vitest.

Run `npm run check` to let TypeScript check all types without running the code.
