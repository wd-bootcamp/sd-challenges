# Chat AIs vs Coding Agents: Chat, Agent or Neither?

Not every task needs the most powerful tool. Sometimes a chat AI is the better choice, sometimes a coding agent, and sometimes no AI at all. In this challenge you decide for ten realistic situations.

## Tasks

1. Open [`SCENARIOS.md`](./SCENARIOS.md).
2. For each scenario, pick one option:
   - **Chat AI**: ask a chat AI in the browser
   - **Coding agent**: let an agent work in your project
   - **Agent, with extra care**: an agent can help, but only with extra precautions (say which ones)
   - **No AI**: do it yourself (or ask a human)
3. Justify your choice in one or two sentences.
4. Discuss your answers with a partner. Find the scenarios where you disagree and try to convince each other.

## Notes

- There is not always one right answer. A good justification is more important than the choice itself.
- Think about: Does the task need access to many files? Do you need to _learn_ something? What happens if the result is wrong? Which data would leave your machine?
