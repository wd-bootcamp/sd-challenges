# Chat AIs vs Coding Agents: Agent Transcript

You haven't used a coding agent yet, but you can already learn a lot from watching one. In this challenge you read the transcript of a short Claude Code session and take it apart step by step.

## Tasks

1. Read [`TRANSCRIPT.md`](./TRANSCRIPT.md) once from top to bottom without taking notes. What happened, in one sentence?
2. Read it again and answer the questions in [`ANSWERS.md`](./ANSWERS.md).
3. Compare your answers with a partner. Where did you label a step differently? Why?

## Notes

- You don't need to install anything for this challenge.
- The transcript is slightly simplified, but it shows what a real Claude Code session looks like in the terminal. You will see the same kind of output in the afternoon.
- `npm test -- --run` runs Vitest once instead of in watch mode. Agents use it because they can't press `q` to stop the watcher.
