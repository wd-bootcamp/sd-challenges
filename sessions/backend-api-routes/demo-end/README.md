# Quotes API: Demo End

The end of the live demo: read, create and delete routes for quotes (in memory), a 404 handler and an error handler. There is no input validation, on purpose.

```bash
npm i
npm run dev
```

Try the routes with the Bruno collection in `bruno/`: open the folder in Bruno (**Open Collection**), select the environment `Local` and send the requests, or run them all with the **Runner**. The data is in memory: restart the server to reset it.
