# TypeScript Basics: Spot the Errors

This challenge is about finding and fixing type errors.

## Tasks

Each snippet in `./src/index.ts` contains at least one type error.

- Step 1: Before you look at your editor, predict the error message for each snippet.
- Step 2: Check your prediction in the editor or with `npm run check`.
- Step 3: Fix the code so that `npm run check` reports no errors.
- Step 4: Answer the questions at the end of the file as comments.

## Notes

- You only have to touch the `./src/index.ts` file.
- This exercise is meant to contain errors when you start. That is the point.

## Development

To work locally, please install the dependencies using `npm i` first.

Run `npm run start` to run `src/index.ts` and re-run it whenever you save.

Run `npm run check` to let TypeScript check all types without running the code. Your editor shows the same errors, so keep an eye on the red squiggles.

### Scripts

You can use the following commands:

- `npm run start` to run the code in the terminal
- `npm run check` to type-check the project
