# TypeScript Basics: Predict the Type

This challenge is about type inference: predicting which types TypeScript infers by itself and when you still have to write a type annotation.

## Tasks

The tasks for this challenge are outlined in the comments inside the `./src/index.ts` file.

## Notes

- You only have to touch the `./src/index.ts` file.
- Hover over a variable in your editor to see its inferred type. Write down your prediction first, then check it.
- This challenge has no output in the terminal. Your editor and `npm run check` do the work.
- Some types will look unfamiliar. Don't worry, you will meet them again in the next session.

## Development

To work locally, please install the dependencies using `npm i` first.

Run `npm run start` to run `src/index.ts` and re-run it whenever you save.

Run `npm run check` to let TypeScript check all types without running the code. Your editor shows the same errors, so keep an eye on the red squiggles.

### Scripts

You can use the following commands:

- `npm run start` to run the code in the terminal
- `npm run check` to type-check the project
