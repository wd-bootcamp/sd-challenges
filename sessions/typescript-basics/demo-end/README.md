## TypeScript Basics: Demo End

Clone this demo to your computer:

```sh
npx ghcd@latest wd-bootcamp/sd-challenges/tree/main/sessions/typescript-basics/demo-end -i
```

## Development

> ❗️ This project is TypeScript with Node only. Check the terminal for the output and your editor for type errors.

To work locally, please install the dependencies using `npm i` first.

### Scripts

You can use the following commands:

- `npm run start` to run `src/index.ts` and re-run it whenever you save
- `npm run check` to type-check the project
