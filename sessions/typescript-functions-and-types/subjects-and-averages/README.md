# TypeScript Functions and Types: Subjects and Averages

This is an open-ended bonus challenge about modelling data with types.

## Tasks

This challenge extends the _Grade Type_ challenge. The starter code in `./src` contains the `Student` and `Grade` types and a `printStudent` function. The tasks are outlined in the comments inside the `./src/index.ts` file.

## Notes

- There is no single correct solution. Discuss your design with a partner.

## Development

To work locally, please install the dependencies using `npm i` first.

Run `npm run start` to run `src/index.ts` and re-run it whenever you save.

Run `npm run check` to let TypeScript check all types without running the code. Your editor shows the same errors, so keep an eye on the red squiggles.

### Scripts

You can use the following commands:

- `npm run start` to run the code in the terminal
- `npm run check` to type-check the project
