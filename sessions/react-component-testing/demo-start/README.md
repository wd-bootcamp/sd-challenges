# React Component Testing: Demo Start

This is the starter of the React Component Testing demo: a small app to manage your favorite movies. The app has three components, `Movies`, `Movie` and `Form`, but no tests yet.

## Notes

- Vitest and React Testing Library are already set up. You can write your tests right next to the components in files ending with `.test.jsx`.

## Development

To work locally, please install the dependencies using `npm i` first (Node.js 22.22 or newer is required).

Run `npm run dev` to start a development server and open the displayed URL in a browser.

Use `npm run test` to run the tests.

### Scripts

You can use the following commands:

- `npm run dev` to start a development server
- `npm run build` to build the project
- `npm run serve` to preview the production build
- `npm run test` to run the tests with Vitest
