# React Router: Demo End

This is the end result of the React Router demo: every part of the Rick and Morty gallery has its own URL.

- `/` shows the welcome page
- `/characters` shows all characters
- `/characters/:id` shows the details of one character
- `/new` shows the form to add a character

## Development

To work locally, please install the dependencies using `npm i` first.

Run `npm run dev` to start a development server and open the displayed URL in a browser.

### Scripts

You can use the following commands:

- `npm run dev` to start a development server
- `npm run build` to build the project
- `npm run serve` to preview the production build
