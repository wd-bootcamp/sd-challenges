## Agent Skills, MCP Servers, Sub-Agents & Risks: Demo

Clone this demo to your computer:

```sh
npx ghcd@latest wd-bootcamp/sd-challenges/tree/main/sessions/agent-skills-mcp-sub-agents-and-risks/demo -i
```

This is the Movie Tracker from the TypeScript React session, now with Vitest. The coach uses it to show skills, the Playwright MCP server, sub-agents and a prompt injection live. What the project looks like after the demo depends on the live run.

## Development

To work locally, please install the dependencies using `npm i` first.

Run `npm run dev` to start a development server and open the displayed URL in a browser.

Run `npm test` to run the tests and `npm run check` to let TypeScript check all types.
