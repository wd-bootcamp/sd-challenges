# Prompt Makeover

Each prompt below was sent to a coding agent working on the Bookshelf app. Each of them leaves the agent guessing.

For every prompt:

1. Write down **what is missing**: the goal, context, constraints, a definition of done, or a smaller scope.
2. Write a **better version** below it.

> 💡 A good agent prompt answers four questions: _What do I want and why?_ _Where should the agent look?_ _What must it not do?_ _How do we both know it's done?_
