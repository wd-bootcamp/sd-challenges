```sh
npx ghcd@latest wd-bootcamp/sd-challenges/tree/main/sessions/agent-prompting-and-workflows/demo -i
```

This is the Movie Tracker from the TypeScript React session. It contains a bug: every movie shows as liked and the like button seems to do nothing.

## Development

To work locally, please install the dependencies using `npm i` first.

Run `npm run dev` to start a development server and open the displayed URL in a browser.

Run `npm test` to run the tests with Vitest.

Run `npm run check` to let TypeScript check all types without running the code.
